# 🤖 ربات دانلودر تلگرام (yt-dlp)

یوتیوب، اینستاگرام، تیک‌تاک، X، فیسبوک، ردیت، ساندکلاود، ویمیو و صدها سایت دیگه.

## ویژگی‌ها
- لینک که بفرستی **فوراً** منوی کیفیت میاد؛ عنوان و حجم هر کیفیت چند ثانیه بعد روی همون منو آپدیت میشه
- کار در پیوی و گروه (توی گروه فقط لینک سایت‌های شناخته‌شده یا `/dl` روی ریپلای)
- دکمه‌های رنگی تلگرام (آبی / سبز / قرمز)
- کش file_id: لینکی که قبلاً دانلود شده، فوری ارسال میشه
- اگه حجم از حد تلگرام بیشتر بشه، خودکار کیفیت پایین‌تر امتحان میشه
- پنل ادمین `/admin`: آمار کلی، کاربران، مصرف ۷ روزه، پرمصرف‌ها، جستجو/بن/آنبن، پیام همگانی، حالت تعمیر
- ضد کرش: هندلر خطا، ری‌استارت خودکار polling، تایم‌اوت دانلود، پاکسازی فایل موقت، ری‌استارت Railway
- هر بار استارت، yt-dlp به آخرین نسخه آپدیت میشه

## راه‌اندازی روی Railway
1. پروژه رو توی GitHub بذار و توی Railway **Deploy from GitHub** بزن (Dockerfile خودکار شناسایی میشه).
2. **Variables**: `BOT_TOKEN` و `ADMIN_IDS` (آیدی عددی خودت).
3. **Volume** بساز و روی مسیر `/app/data` مونت کن (دیتابیس اینجا ذخیره میشه).
4. فقط **۱ replica**. سرویس رو بدون دامنه/پورت بذار (worker).

## تنظیمات مهم
- **گروه**: توی BotFather → `/setprivacy` → Disable، یا بات رو ادمین گروه کن.
- **فایل بزرگ‌تر از 50MB**: یه Local Bot API Server جدا روی Railway بالا بیار و `LOCAL_API_URL` رو بذار (سقف 2GB).
- **اینستاگرام/یوتیوب (بلاک یا لاگین)**: با افزونه «Get cookies.txt LOCALLY» کوکی بگیر، با `base64 -w0 cookies.txt` تبدیل کن و توی `COOKIES_B64` بذار.
- دکمه رنگی با `COLORED_BUTTONS=0` خاموش میشه.

## محدودیت‌ها
پست‌های فقط‌عکس/کاروسل اینستاگرام و محتوای خصوصی با yt-dlp پشتیبانی کامل ندارن. لایو پشتیبانی نمیشه.
سایت‌های دانلود کپی‌رایتی/محتوای دیگران رو فقط در حد قانون و استفاده شخصی استفاده کنید.
